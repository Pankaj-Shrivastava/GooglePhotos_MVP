Image Metadata Extraction Guide
Image Analysis (image-test.jpg)

• Definition: Studio portrait of a young child holding an ice cream cone against a white background.

• Visual Content: Boy with brown hair/eyes wearing a yellow polo shirt, holding a waffle cone with white ice cream, chocolate drizzle, and red syrup.

Visual Content as Metadata Visual elements can be converted into:

• Keywords/Tags

• Alt Text (Accessibility)

• Captions/Titles

Sensory Cues yellow, bright, warm, smiling, smooth, soft, sweet, cold, crunchy, sticky, sugary, chocolatey, colorful

App Building Instructions To extract comprehensive metadata, use a two-part approach:

1. AI Prompt (For Visual & Sensory Extraction) Use a Vision-Language AI with a strict JSON prompt extracting:

• primary_subjects

• descriptive_tags

• sensory_cues

• mood_and_tone

• alt_text

• dominant_colors

2. Code Logic (For Technical Extraction) Use code libraries to extract EXIF data (like Date Taken), as AI cannot reliably guess technical data:

• Python: Pillow or exifread

• Node.js: exif-parser

• Swift: CGImageSourceCopyPropertiesAtIndex

• Kotlin: ExifInterface
